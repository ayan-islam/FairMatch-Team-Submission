# Faculty contribution evidence

Use these repository pages during the demonstration:

- Commits on `main`: <https://github.com/ayan-islam/FairMatch-Team-Submission/commits/main/>
- Contributors: <https://github.com/ayan-islam/FairMatch-Team-Submission/graphs/contributors>
- Pull requests: <https://github.com/ayan-islam/FairMatch-Team-Submission/pulls?q=is%3Apr>
- Branches: <https://github.com/ayan-islam/FairMatch-Team-Submission/branches>

For each member, show:

1. Their pull request and explanation.
2. Their code diff.
3. Their automated-test result.
4. Their commit authored by their own GitHub account.
5. The merged commit on `main`.
6. The feature running in FairMatch.

The number of commits is less important than a clear, working change the member can explain. Do not split or duplicate commits only to increase activity counts.
